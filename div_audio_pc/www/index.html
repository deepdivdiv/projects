    마우스 동작

    목록 클릭: 선택 (Ctrl, Shift로 여러 곡)
    목록 더블클릭: 재생
    고른 줄이나 폴더 제목 줄 끌기: 순서 변경
    고르지 않은 줄이나 빈 곳 끌기: 범위 선택 (Ctrl: 더하기)
    목록 오른쪽 클릭: 메뉴
    썸네일 클릭: 재생/정지
    썸네일 왼쪽/오른쪽 더블클릭: 뒤로/앞으로 건너뛰기
    재생 화면 좌우로 끌기: 이전/다음 곡
    북마크 왼쪽으로 끌기: 삭제
    배속 버튼 좌우로 끌기: 속도 변경

    키보드

    Space: 재생/정지
    Enter: 고른 곡 재생
    Delete: 고른 곡을 목록에서 빼기
    Ctrl + A: 전체 선택
    Ctrl + O: 파일 추가
    ← →: 뒤로/앞으로 건너뛰기
    Ctrl + ← →: 이전/다음 곡
    ↑ ↓: 음량
    B: 북마크 추가
    S: 재생 속도 변경
    P: 플레이어 접기/펼치기
    Ctrl + F: 목록 검색
    Esc: 뒤로 가기
    키보드의 미디어 키도 사용할 수 있습니다.
