# Google Play 등록 체크리스트

순서대로 진행합니다. 메뉴 이름과 조건은 바뀔 수 있으니 Play Console 화면의 안내를 우선합니다.

## 0. 먼저 할 일

- [ ] `DIV_AUDIO_APP_store_test.apk`를 폰에 설치해서 아래를 확인
  - [ ] 음악 폴더 연결, 하위 폴더 이동
  - [ ] 곡 재생, 시크, 건너뛰기, 백그라운드 재생
  - [ ] ZIP 열기, ZIP 안 곡 재생과 시크
  - [ ] 앱을 껐다 켜도 폴더 연결과 북마크 유지
  - [ ] 북마크 파일 저장(Download)과 공유
- [ ] `keystore` 폴더를 USB, 클라우드 등 **PC 밖 안전한 곳에 백업**
- [ ] 개인정보처리방침의 `[시행일]`, `[운영자 이름]`, `[문의 이메일]` 채우기
- [ ] `privacy-policy.html`을 공개 URL로 올리기 (GitHub Pages 등)

## 1. 개발자 계정

- [ ] [Play Console](https://play.google.com/console) 가입, 등록비 결제, 신원 인증
- [ ] 계정 유형 선택: 개인 또는 조직. 개인 계정은 3번의 비공개 테스트 조건이 적용됩니다.

## 2. 앱 만들기

- [ ] 앱 이름 `DIV AUDIO APP`, 기본 언어 한국어, 앱, 무료 선택
- [ ] Play 앱 서명 사용 (기본값)
- [ ] `listing.md` 내용과 이미지 입력

**앱 콘텐츠 입력값**

| 항목 | 입력 |
|---|---|
| 개인정보처리방침 | 공개한 URL |
| 광고 | 없음 |
| 앱 액세스 | 로그인 없음. 심사용 안내에 "첫 화면에서 음악 폴더를 연결하면 모든 기능을 사용할 수 있습니다"라고 적기 |
| 콘텐츠 등급 | 설문 작성. 폭력, 성적 콘텐츠, 사용자 간 소통, 위치 공유 모두 없음 |
| 타겟층 | 만 13세 이상 권장 |
| 데이터 보안 | 수집하는 데이터 없음, 공유하는 데이터 없음 |
| 뉴스, 금융, 건강, 정부 앱 | 해당 없음 |
| 포그라운드 서비스 권한 | 미디어 재생. 요청이 있으면 앱을 내려도 재생이 이어지고 알림바에서 조작되는 화면 녹화 영상 제출 |

개인 계정은 테스터 12명이 14일 동안 계속 참여해야 프로덕션을 신청할 수 있습니다.

- [ ] 비공개 테스트 트랙 만들기

- [ ] 테스터에게 참여 링크 전달, 설치 후 실제로 사용 요청
- [ ] 14일 유지, 받은 의견 기록

## 4. 프로덕션 신청과 공개

- [ ] 프로덕션 액세스 신청 (테스트 방법과 의견 요약 작성)

## 수정본을 올릴 때

- `android/app/build.gradle`의 `versionCode`를 1 올리기 (같은 번호는 업로드 불가)
- `keystore` 폴더가 있는 상태로 AAB를 다시 빌드

## 바꿀 수 없는 것

- **패키지 ID `com.snet.divaudio`**: 첫 업로드 뒤에는 바꿀 수 없습니다. 다른 ID를 원하면 업로드 전에 `android/app/build.gradle`에서 바꿔야 합니다.
