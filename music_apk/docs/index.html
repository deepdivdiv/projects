DIV AUDIO APP

iOS 버전 __VERSION__ · __DATE__ · iOS 15 이상
이 앱은 App Store가 아닌 직접 설치(사이드로딩) 방식으로 배포됩니다. 무료 Apple ID로 서명하므로 7일마다 다시 서명(갱신)해야 하고, 한 번에 최대 3개 앱까지 설치할 수 있습니다. PC 없이 쓰기: 웹앱 버전 열기

방법 1. AltStore / SideStore 추천

AltStore 또는 SideStore가 아이폰에 이미 설치되어 있다면 버튼 한 번으로 설치됩니다. 갱신도 앱이 알아서 처리합니다.

AltStore로 설치 SideStore로 설치 AltStore에 소스 추가 (업데이트 자동 알림)

AltStore가 없다면: PC에 AltServer를 설치하고, 아이폰을 USB로 연결한 뒤 AltServer 메뉴에서 Install AltStore를 누르세요.

방법 2. Sideloadly (Windows / Mac PC)

  1. PC에서 아래 버튼으로 DIV_AUDIO_APP.ipa를 내려받습니다.
  2. Sideloadly를 설치하고 실행합니다. (Windows는 iTunes·iCloud 설치 필요)
  3. 아이폰을 USB로 연결하고, ipa 파일을 Sideloadly 창에 끌어다 놓습니다.
  4. Apple ID를 입력하고 Start를 누릅니다.
IPA 파일 내려받기

설치 후 아이폰에서 꼭 할 일

  1. 개발자 모드 켜기 (iOS 16 이상): 설정 → 개인정보 보호 및 보안 → 개발자 모드 → 켬 → 재시동
  2. 개발자 신뢰: 설정 → 일반 → VPN 및 기기 관리 → 내 Apple ID 선택 → 신뢰
  3. 앱을 실행하고 음악 폴더 접근을 허용합니다.
